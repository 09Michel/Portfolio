AfriFood App

A comprehensive web development project focused on delivering rich culinary experiences through responsive, user-centric design.

ABOUT THE PROJECT

Bridging Culture and Technology

Javascript python react typescript Tailwind css react vite
Visit Live App ↗

AfriFood is a high-performance web application built to bridge the gap between traditional culinary heritage and modern technology. Developed using React and Supabase, the platform offers a seamless, real-time experience for discovering and mastering authentic recipes from across the continent and beyond.

Role & Responsibilities
As the lead developer and designer, I was responsible for the full development lifecycle, from initial UI/UX wireframing in VS Code to deployment on Vercel.

  • Architecture: Designed a scalable database schema using Supabase to handle real-time recipe updates and user data.
  • Frontend: Built a responsive, mobile-first interface using React to ensure accessibility for users in the kitchen or on the go.

Core Innovations

  • AI Culinary Assistant: I integrated an intelligent AI companion that provides real-time guidance, suggests ingredient substitutions, and helps users scale recipes based on serving sizes.
  • Location-Based Sourcing (Maps API): To ensure users can find authentic ingredients, I incorporated a Geolocation feature. The app identifies the user's location to highlight the nearest specialty spice stores and markets, turning a digital recipe into a tangible cooking experience.

Technical Challenges & Solutions

  • Real-Time Data & Performance: Managing a growing library of recipes and location data while maintaining fast load times.
    Solution: Optimized data fetching through Supabase and implemented a clean, grid-based UI that ensures the discovery process remains fast and intuitive.
  • Bridging Digital & Physical: Creating a workflow that helps users find ingredients.
    Solution: Integrated a Maps interface that filters for local vendors based on the specific recipe the user is currently viewing.

Impact
AfriFood is more than a recipe book; it is a specialized tool that empowers users to explore diverse flavors with the help of AI and local sourcing, making authentic cooking more accessible than ever.
